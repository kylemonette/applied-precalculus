    Evaluating Logarithms.

    Evaluate without using a calculator, or say that the expression is undefined.
    🔗
    1.
    \(\ln (e^9)\)
    🔗
    Solution.
    If \(\ln (e^9)=x\) then \(e^x = e^9\text{,}\) so \(x\) must be \(9\text{.}\) Hence \(\ln (e^9)=9\text{.}\)
    🔗
    🔗
    🔗
    2.
    \(\log_4 (\sqrt{4^3})\)
    🔗
    Solution.
    If \(\log_4(\sqrt{4^3} )=x\) then \(4^x = \sqrt{4^3} \text{.}\) Note that \(\sqrt{4^3} = (4^3)^{1 /2} = 4^{3 /2}\text{.}\) Therefore \(4^x = 4^{3 /2}\) and thus \(x=\frac{3}{2}\) is the value of the logarithm.
    🔗
    🔗
    🔗
    3.
    \(\log (0.0001)\)
    🔗
    Solution.
    Recall: \(\log \) with no subscript means base \(10\)
    🔗
    Because \(0.0001 = 10^{-4}\text{,}\) then this is \(\log (10^{-4})\text{.}\) If \(\log (10^{-4})=x\text{,}\) then \(10^x = 10^{-4}\text{.}\) Therefore \(x=-4\) and so \(\log (0.0001)=-4\text{.}\)
    🔗
    🔗
    🔗
    4.
    \(\log_2(-8)\)
    🔗
    Solution.
    This is not defined. Recall that \(\log _b(x)\) is only defined for \(x \gt 0\text{.}\)
    🔗
    🔗
    🔗
    5.
    \(\log_7 \pbr{\dfrac{1}{343}}\)
    🔗
    Solution.
    Note that \(343 = 7^3\) so that \(\frac{1}{343}=7^{-3}\text{.}\) Therefore \(\log_7(7^{-3})=x\) means that \(7^x = 7^{-3}\) and so \(x=-3\text{,}\) implying that the logarithm value is \(-3\text{.}\)
    🔗
    🔗
    🔗
    6.
    \(\log_4(16)\)
    🔗
    Solution.
    Because \(16=4^2\text{,}\) then we have \(\log _4(4^2)\text{.}\) If \(\log _4(4^2)=x\text{,}\) then \(4^x=4^2\) and so \(x=2\text{.}\) Therefore \(\log _4(16)=2\text{.}\)
    🔗
    🔗
    🔗
    7.
    \(\ln \pbr{\dfrac{e^2}{\sqrt[3]{e}}}\)
    🔗
    Solution.
    We can simplify the fraction here to be
    \begin{equation*} \frac{e^2}{\sqrt[3]{e} } \quad = \quad \frac{e^2}{e^{1 /3}} \quad = \quad e^{2-1/3} \quad = \quad e^{5/3} . \end{equation*}
    Now, we are computing \(\ln (e^{5 /3})\text{.}\) If \(\ln (e^{5 /3})=x\text{,}\) then \(e^x = e^{5 /3}\) so \(x=\frac{5}{3}\) is the logarithm value.
    🔗
    🔗
    🔗
    8.
    \(\log_9 \pbr{\dfrac{1}{6561}}\)
    🔗
    Solution.
    Note that \(6561 = 9^4\) and so \(\frac{1}{6561} = 9^{-4}\text{.}\) Therefore we have \(\log _9(9^{-4})\) and this is just \(-4\text{.}\)
    🔗
    🔗
    🔗
    🔗

    9.

    Use the definition of the logarithm to solve each equation.
    🔗
    (a)
    \(2^x=63\)
    🔗
    Solution.
    With the definition of the logarithm, then \(\log _2(63)=x\) is the exact solution. As a decimal, this is \(x=5.97728\) (do this on your calculator).
    🔗
    🔗
    🔗
    (b)
    \(6(10)^x-4=5\)
    🔗
    Solution.
    Adding \(4\) to both sides, then \(6 \cdot 10^x = 9\text{.}\) Dividing by \(6\) yields \(10^x = \frac{9}{6}=\frac{3}{2}\text{.}\) Now, by the definition of the logarithm this means that \(\log(3 /2) = x\text{.}\) Recall that \(\log \) with no subscript is base \(10\text{.}\) As a decimal, \(x=0.17609\text{.}\)

    Worksheet 6.2 Practice Worksheet
    

    1.

    Use properties of the logarithm to rewrite each expression in terms of \(\log x\) and \(\log y\) or state that this is not possible.
    🔗
    (a)
    \(\log(xy^4)\)
    🔗
    Solution.
    \begin{equation*} \log (xy^4) \quad = \quad \log (x) + \log (y^4) \quad = \quad \log (x) + 4 \log (y). \end{equation*}
    🔗
    🔗
    🔗
    (b)
    \(\log (\frac{3x^2}{y})\)
    🔗
    Solution.
    \begin{align*} \log \pbr{\frac{3x^2}{y}} \amp \quad = \quad \log (3x^2) - \log (y) \\ \amp \quad = \quad \log (3) + \log (x^2) - \log (y) \\ \amp \quad = \quad \log (3) + 2\log (x) - \log (y). \end{align*}
    🔗
    🔗
    🔗
    (c)
    \(\log (x-y^4)\)
    🔗
    Solution.
    There is no rule for subtracting inside of a logarithm, so nothing else can be done here.
    🔗
    🔗
    🔗
    (d)
    \(\log(\sqrt[3]{xy})\)
    🔗
    Solution.
    Recall that \(\sqrt[3]{xy} = (xy)^{1 /3} \text{.}\) Therefore
    \begin{align*} \log \pbr{\sqrt[3]{xy} } \amp \quad = \quad \log \pbr{(xy)^{1 /3}}\\ \amp \quad = \quad \frac{1}{3} \log (xy) \\ \amp \quad = \quad \frac{1}{3}\pbr{\log (x) + \log (y)}. \end{align*}
    🔗
    🔗
    🔗
    (e)
    \(\log(\frac{1}{x^3y})\)
    🔗
    Solution.
    \begin{align*} \log \pbr{\frac{1}{x^3y}} \amp \quad = \quad \log (1) - \log (x^3y) \\ \amp \quad = \quad 0 - \pbr{\log (x^3) + \log (y)} \\ \amp \quad = \quad -3\log (x) - \log (y). \end{align*}
    🔗
    🔗
    🔗
    🔗

    2.

    Write each expression as a single logarithm.
    🔗
    (a)
    \(\log_9(2)-2\log_9(5)\)
    🔗
    Solution.
    Moving the coefficient \(2\) inside the second logarithm, then we have
    \begin{equation*} \log _9(2) - \log_9(5^2) \quad = \quad \log _9\pbr{\frac{2}{25}} . \end{equation*}
    🔗
    🔗
    🔗
    (b)
    \(2\log_3(x)+12\log_5(y)\)
    🔗
    Solution.
    These cannot be combined or simplified any further because the two logarithms have different bases. Indeed, the formulas we learned in section 6.2 only apply if the bases of all the logarithms involved are the same.
    🔗
    🔗
    🔗
    (c)
    \(\log(x)+\frac{\log(y)}{2}+\frac{\log(z)}{3}\)
    🔗
    Solution.
    \begin{align*} \log(x)+\frac{\log(y)}{2}+\frac{\log(z)}{3} \amp \quad = \quad \log (x) + \frac{1}{2} \log (y) + \frac{1}{3} \log (z)\\ \amp \quad = \quad \log (x) + \log (y^{1 /2}) + \log (z ^{1 /3})\\ \amp \quad =\quad \log (x) + \log (\sqrt{y} ) + \log (\sqrt[3]{z})\\ \amp \quad = \quad \log (x \sqrt{y} \sqrt[3]{z}) \end{align*}
    🔗
    🔗
    🔗
    (d)
    \(\log_3(12)-\log_3(7)+4\log_3(z)\)
    🔗
    Solution.
    \begin{align*} \log_3(12)-\log_3(7)+4\log_3(z) \amp \quad = \quad \log_3(12) - \log_3(7) + \log_3(z^4)\\ \amp \quad = \quad \log_3 \pbr{\frac{12}{7}} + \log_3(z^4)\\ \amp \quad = \quad \log_3\pbr{\frac{12}{7}z^4} \end{align*}
    🔗
    🔗

    3.

    Use the natural logarithm or the common logarithm to solve each equation.
    🔗
    REMARK:
    🔗
    We note that the following solutions were done with the natural logarithm, \(\ln \text{.}\) You could have used the common logarithm, \(\log \text{,}\) (base \(10\)). Your final answers for \(x\) will be the same. We advise you use the logarithm that your calculator can compute.
    🔗
    (a)
    \(4^z=15\)
    🔗
    Solution.
    Taking the natural logarithm of both sides yields \(\ln (4^z) = \ln (15)\text{.}\) Then, we can move the exponent \(z\) out to get \(z \ln (4) = \ln (15)\text{.}\) Lastly, divide by \(\ln (4)\) to get
    \begin{equation*} z = \frac{\ln (15)}{\ln (4)} = 1.95345. \end{equation*}
    🔗
    🔗
    🔗
    (b)
    \(5\cdot3^x-35=0\)
    🔗
    Solution.
    Add \(35\) to both sides to get \(5\cdot 3^x = 35\) and then divide by \(5\) to get
    \begin{equation*} 3^x = 7. \end{equation*}
    Now, take the natural logarithm of both sides to obtain \(\ln (3^x) = \ln (7)\) which we simplify as \(x\ln (3) = \ln (7)\text{.}\) Finally,
    \begin{equation*} x = \frac{\ln (7)}{\ln (3)} = 1.77124. \end{equation*}
    🔗
    🔗
    🔗
    (c)
    \(6^x=2^{x-3}\)
    🔗
    Solution.
    Begin by taking the natural logarithm of both sides:
    \begin{equation*} \ln (6^x) = \ln (2^{x-3}). \end{equation*}
    On the left we can move the \(x\) in front, and on the right we can move the whole \(x-3\) term in front:
    \begin{equation*} x\ln (6) = (x-3)\ln (2). \end{equation*}
    Distributing the right side yields \(x\ln (6) = x\ln (2) - 3\ln (2)\text{.}\) Now we want to move the \(x\ln (2)\) term to the left side; the goal being to have all \(x\) terms on one side. Subtracting \(x\ln (2)\) to both sides,
    \begin{equation*} x\ln (6) - x\ln (2) = -3\ln (2). \end{equation*}
    Factoring out \(x\) on the left,
    \begin{equation*} x\pbr{\ln (6) - \ln (2)} = -3\ln (2) \end{equation*}
    and then dividing both sides by \(\ln (6)-\ln (2)\) gives us
    \begin{equation*} x = \frac{-3\ln (2)}{\ln (6)-\ln (2)} = -1.89279. \end{equation*}
    🔗
    🔗
    🔗
    (d)
    \(120\cdot1.06^t=210\cdot1.02^t\)
    🔗
    Solution.
    Taking the natural logarithm of both sides,
    \begin{equation*} \ln (120 \cdot 1.06^t) = \ln (210 \cdot 1.02^t). \end{equation*}
    Expanding both sides,
    \begin{equation*} \ln (120) + \ln (1.06^t) = \ln (210) + \ln (1.02^t) \end{equation*}
    and then moving the exponent to the front gives us
    \begin{equation*} \ln (120) + t \ln (1.06) = \ln (210) + t \ln (1.02). \end{equation*}
    Now we move the \(t \ln (1.02)\) term to the left side by subtracting it over, so that we have all instances of the variable \(t\) on one side. That is,
    \begin{equation*} \ln (120) + t\ln (1.06) - t\ln (1.02) = \ln (210). \end{equation*}
    Now subtracting the \(\ln (120)\) term from both sides we get
    \begin{align*} t\ln (1.06) - t\ln (1.02) \amp \quad = \quad \ln (210) - \ln (120) \\ t \pbr{\ln (1.06)-\ln (1.02)} \amp \quad = \quad \ln (210) - \ln (120). \end{align*}
    Now, solving for \(t\) yields
    \begin{equation*} t = \frac{\ln (210)-\ln (120)}{\ln (1.06)-\ln (1.02)} = 14.5482. \end{equation*}
    🔗
    🔗
    🔗
    (e)
    \(2149(1.045)^y=8200\)
    🔗
    Solution.
    Begin by dividing both sides by \(2149\) to get
    \begin{equation*} 1.045^y = \frac{8200}{2149} . \end{equation*}
    Take the logarithm of both sides:
    \begin{equation*} \ln (1.045^y) = \ln \pbr{\frac{8200}{2149}} \quad \implies \quad y \ln (1.045) = \ln \pbr{\frac{8200}{2149} } . \end{equation*}
    Solving for \(y\) gives us
    \begin{equation*} y = \frac{\ln \pbr{\frac{8200}{2149} } }{\ln (1.045)} = 30.42313. \end{equation*}
    🔗
    🔗
    🔗
    (f)
    \(60(3)^x=25(2)^x\)
    🔗
    Solution.
    Dividing both sides by \(60\) yields
    \begin{equation*} 3^x = \frac{25}{60}\cdot 2^x. \end{equation*}
    One approach is to proceed as in part (d) above. Another is to divide both sides by \(2^x\) which gives us
    \begin{equation*} \frac{3^x}{2^x} = \frac{25}{60} \end{equation*}
    and then we can write the left side as one exponential function as in
    \begin{equation*} \pbr{\frac{3}{2}} ^x = \frac{25}{60}. \end{equation*}
    Now, to solve this we take the logarithm of both sides as usual:
    \begin{equation*} \ln \pbr{\pbr{\frac{3}{2}}^x} = \ln \pbr{\frac{25}{60}} \quad \implies \quad x \ln \pbr{\frac{3}{2}} = \ln \pbr{\frac{25}{60}} . \end{equation*}
    Therefore
    \begin{equation*} x = \frac{\ln (25 /60)}{\ln (3 /2)} = -2.15917 . \end{equation*}
    🔗

    REMARK:

    1.

    Find the doubling time (for increasing quantity) or the half-life (for decreasing quantity).
    🔗
    (a)
    \(y=150\cdot1.07^t\)
    🔗
    Solution.
    The function is increasing, so we compute the doubling time. Setting the function to twice the initial value, then
    \begin{equation*} 300 = 150 \cdot (1.07)^t. \end{equation*}
    Dividing by the \(150\) yields \(2 = (1.07)^t\) and then taking the natural logarithm of both sides gives us
    \begin{equation*} \ln (2) = \ln (1.07^t) \quad \implies \quad \ln (2) = t \ln (1.07). \end{equation*}
    Therefore the doubling time is
    \begin{equation*} t = \frac{\ln (2)}{\ln (1.07)} = 10.24477 . \end{equation*}
    🔗
    🔗
    🔗
    (b)
    \(y=63\cdot0.61^t\)
    🔗
    Solution.
    This function is decreasing, so we compute the half-life. Setting the function to half its initial value, then
    \begin{equation*} 31.5 = 63 \cdot (0.61)^t. \end{equation*}
    Dividing by \(63\) yields \(\frac{1}{2} = (0.61)^t\) and then taking the natural logarithm of both sides gives us
    \begin{equation*} \ln (1 /2) = \ln (0.61^t) \quad \implies \quad \ln (1 /2) = t \ln (0.61). \end{equation*}
    Therefore the half-life is
    \begin{equation*} t = \frac{\ln (1 /2)}{\ln (0.61)} = 1.40229. \end{equation*}
    🔗
    🔗
    🔗
    🔗

    2.

    An investment begins with \(\$2500\) and earns \(1.3\%\) per year.
    🔗
    (a)
    What is the doubling time?
    🔗
    Solution.
    First, find the formula for the function. Because \(A=2500\) and \(r=1.3\% = 0.013\text{,}\) then \(b=1+r = 1.013\) and so
    \begin{equation*} y = 2500 (1.013)^t. \end{equation*}
    To find the doubling time of this function, set it equal to twice the initial value. That is,
    \begin{equation*} 5000 = 2500 (1.013)^t. \end{equation*}
    Dividing by \(2500\) yields \(2 = (1.013)^t\text{.}\) Then take the natural logarithm:
    \begin{equation*} \ln (2) = \ln (1.013^t) \quad \implies \quad \ln (2) = t \ln (1.013). \end{equation*}
    Therefore the doubling-time is
    \begin{equation*} t = \frac{\ln (2)}{\ln (1.013)} = 53.66484 \quad \text{years} . \end{equation*}
    🔗
    🔗
    🔗
    (b)
    How long does it take for the investment to triple?
    🔗
    Solution.
    Now we set the function equal to three times its initial value. That is,
    \begin{equation*} 7500 = 2500 (1.013)^t. \end{equation*}
    Dividing by \(2500\) yields \(3 = (1.013)^t\text{.}\) Taking the natural logarithm,
    \begin{equation*} \ln (3) = \ln (1.013^t) \quad \implies \quad \ln (3) = t \ln (1.013). \end{equation*}
    Therefore the time it takes to triple is
    \begin{equation*} t = \frac{\ln (3)}{\ln (1.013)} = 85.0567 \quad \text{years} . \end{equation*}
    🔗
    🔗
    🔗

    3.

    A radioactive substance decays exponentially. After \(t=4\) days, there is \(20\)mg of the initial amount remaining and after \(t=8\) days, there is \(12\)mg of the initial amount remaining. When will \(20\%\) of the initial amount remain?
    🔗
    Solution.
    First, we find the formula for the function. Two points are given: \((4,20)\) and \((8,12)\text{.}\) Using these, form two equations:
    \begin{equation*} 20 = A \cdot b^4 \quad \text{and} \quad 12 = A\cdot b^8. \end{equation*}
    Dividing them we get
    \begin{equation*} \frac{12}{20} = \frac{A\cdot b^8}{A\cdot b^4} \quad \implies \quad \frac{3}{5} = b^4 \end{equation*}
    and so \(b=\sqrt[4]{3 /5} = (3 /5)^{1 /4} \text{.}\) Now, we can update the formula:
    \begin{equation*} y = A \cdot \pbr{\pbr{\frac{3}{5}}^{1 /4}}^t \quad \implies \quad y= A \cdot \pbr{\frac{3}{5}} ^{t /4}. \end{equation*}
    Plugging in a point, say \((4,20)\text{,}\) then
    \begin{equation*} 20 = A \cdot \pbr{\frac{3}{5}}^{4 /4} \quad \implies \quad 20 = A \pbr{\frac{3}{5}} \quad \implies \quad A = \frac{100}{3}. \end{equation*}
    Now we know that the formula for the function is
    \begin{equation*} y = \frac{100}{3} \cdot \pbr{\frac{3}{5}} ^{t /4}. \end{equation*}
    Now, note that \(20\%\) of the original amount is \(20\%\) of \(\frac{100}{3}\) which is \(0.2 \times \frac{100}{3}\text{.}\) So we set the function equal to this number:
    \begin{equation*} 0.2 \pbr{\frac{100}{3}} = \frac{100}{3} \cdot \pbr{\frac{3}{5}} ^{t /4}. \end{equation*}
    Divide both sides by \(\frac{100}{3}\text{:}\)
    \begin{equation*} 0.2 = \pbr{\frac{3}{5}} ^{t/4}. \end{equation*}
    Take the natural logarithm of both sides:
    \begin{equation*} \ln (0.2) = \ln \pbr{\pbr{\frac{3}{5}} ^{t/4}} \quad \implies \quad \ln (0.2) = \frac{t}{4} \ln \pbr{\frac{3}{5}} . \end{equation*}
    Therefore
    \begin{equation*} t = \frac{4\ln (0.2)}{\ln (3 /5)} = 12.6026 \quad\text{days} . \end{equation*}
    🔗
    🔗
    🔗

    4.

    A \(24\)kg sample of radioactive material loses \(3\%\) of its mass every \(8\) days.
    🔗
    (a)
    What is the half-life?
    🔗
    Solution.
    Here, \(A=24\) and \(r=-3\% = -0.03\text{.}\) So \(b=1+r = 1+(-0.03) = 0.97\text{.}\) Also, in the context of section 5.4, \(T=8\) days here. Therefore the formula that describes this is
    \begin{equation*} y = A \cdot b^{t /T} = 24 \cdot (0.97)^{t /8} . \end{equation*}
    To find the half-life, set this function equal to half its initial value which is \(12\) here. Therefore,
    \begin{equation*} 12 = 24 \cdot (0.97)^{t /8}. \end{equation*}
    Dividing by \(24\) and then taking the natural logarithm,
    \begin{equation*} \ln \pbr{\frac{1}{2}} = \ln (0.97^{t /8}) \quad \implies \quad \ln \pbr{\frac{1}{2}} = \frac{t}{8} \ln (0.97). \end{equation*}
    Therefore
    \begin{equation*} t = \frac{8 \ln (1 /2)}{\ln (0.97)} = 182.0528 \quad \text{days} . \end{equation*}
    🔗
    🔗
    🔗
    (b)
    How long will it take before the sample has shrunk to a weight of \(2\) kg?
    🔗
    Solution.
    Using the formula in part (a), we set \(y=2\) and solve for \(t\text{.}\) That is,
    \begin{equation*} 2 = 24 \pbr{0.97} ^{t /8}. \end{equation*}
    Dividing by \(24\) and then taking the natural logarithm,
    \begin{equation*} \ln \pbr{\frac{1}{12}} = \ln (0.97^{t/8}) \quad \implies \quad \ln \pbr{\frac{1}{12}} = \frac{t}{8} \ln (0.97). \end{equation*}
    Solving for \(t\) yields
    \begin{equation*} t = \frac{8\ln (1 /12)}{\ln (0.97)} = 652.6519 \quad\text{days} . \end{equation*}
    🔗
    🔗
    🔗
    🔗

    5.

    A rain forest’s area is being reduced by \(18\%\) every \(9\) years. How long does it take for the rain forest to reach one-half of its starting area?
    🔗
    Solution.
    Here we have the growth rate \(r=-18\% = -0.18\text{,}\) so \(b=1+r = 0.82\text{,}\) and \(T=9\) years. Therefore the formula that describes this is
    \begin{equation*} y = A \cdot b^{t /T} = A (0.82)^{t /9}. \end{equation*}
    Note that we do not know \(A\text{,}\) nor have enough information to find it. But, it is actually not needed as the following will illustrate. To find the half-life, set the function to \(\frac{1}{2}A\text{:}\)
    \begin{equation*} \frac{1}{2}A = A (0.82)^{t /9} \quad \implies \quad \frac{1}{2} = (0.82)^{t /9} \end{equation*}
    after dividing by \(A\text{.}\) Taking the natural logarithm,
    \begin{equation*} \ln \pbr{\frac{1}{2}} = \ln (0.82^{t /9}) \quad \implies \quad \ln \pbr{\frac{1}{2}} = \frac{t}{9} \ln (0.82). \end{equation*}
    Solving for \(t\text{,}\) we get
    \begin{equation*} t = \frac{9\ln (1 /2)}{\ln (0.82) } = 31.4351 \quad \text{years} . \end{equation*}

    6.

    A population has a continuous growth rate of \(12.3\%\text{.}\) What is the population’s doubling time?
    🔗
    Solution.
    Given that \(k=12.3\% = 0.123\text{,}\) then the function is
    \begin{equation*} y = A e^{0.123 t} \end{equation*}
    where \(A\) is unknown, but is not needed anyway. Setting the formula above to \(2A\text{,}\) then
    \begin{equation*} 2A = A e^{0.123t}\quad \implies \quad 2 = e^{0.123 t}. \end{equation*}
    Taking the natural logarithm of both sides yields
    \begin{equation*} \ln (2) = \ln (e^{0.123t}) \quad \implies \quad \ln (2) = 0.123t. \end{equation*}
    Solving for \(t\) gives us
    \begin{equation*} t = \frac{\ln (2)}{0.123} = 5.63534 \quad \text{years}. \end{equation*}
